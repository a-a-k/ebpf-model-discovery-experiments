# Repository instructions

Methods and scope are defined in [the protocol](docs/PROTOCOL_V6.md).

Run applications, VMs, model construction, simulation and scientific artifact
processing in GitHub Actions. Local work is source editing, static analysis and
focused synthetic checks. Use standard workers and the full 360-minute job limit.

Preserve actual sources, input closures and producing jobs/attempts. Freeze all
four models before independent targets. Keep adverse, unavailable and unknown
outcomes and every preparation, failed, repeated and early-stop cost. Unmeasured
human work remains unknown.

Scientific implementation, hypothesis changes and success claims require a
separate skeptic check against the original feasibility criterion, strongest
equally informed baselines, proposed causal mechanism and complete cost scope.
Review actual external outcomes before claiming usefulness or completion.
