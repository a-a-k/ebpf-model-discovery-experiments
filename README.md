# eBPF model discovery in distributed microservice applications

**Status: implementation in progress; no application experiment has run.**

This repository implements an empirical study of operation-model discovery and simulation with absent or partial application tracing. It evaluates DeathStarBench Social Network, OpenTelemetry Demo and Spring Petclinic Microservices on two independent Linux guests per campaign.

The repository will retain the complete experiment code, GitHub Actions runs, observation provenance, discovered models, independent HTTP/SQL outcomes and a detailed research report. No empirical success is claimed by this initial scaffold.

See [the agreed protocol](docs/PROTOCOL.md) and [the adapter contract](docs/ADAPTER_CONTRACT.md).
