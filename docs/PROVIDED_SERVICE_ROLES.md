# Provided service names in the common observation view

The a434 qualification retained working native Petclinic edges, but the combined
view contained both SDK names and Compose names for the same declared roles.
Exact alias lookup therefore made required caller/callee roles ambiguous.
This is a reconciliation defect, not evidence that the collector lost those calls.

Before implementation, the main agent and the independent skeptic give ORIGINAL
feasibility GO for extending the existing supplied-alias mechanism. The original
question is discovery and useful simulation with absent/incomplete native traces.
The strongest simple baseline is exact lookup of the same provided deployment
names, given equally to every source arm and the direct baseline. No advantage
over that lookup is claimed. The causal repair is consistent naming across root
selection, graph presentation and fault binding, not additional observed calls.

Read literal OTEL_SERVICE_NAME and service.instance.id from retained rendered
Compose files; match their node/project/service to actual inventory rows. Freeze
file hashes, declaration locations and separate instance slots in the existing
alias table. Admit Compose-name carriers only with the existing receiver digest
and verified runtime ownership. Keep the exact Docker-name provenance rule.
Permit multiple carriers for a target only when those supplied rows explicitly
declare the same logical role with distinct instance slots. Unproved collisions
remain unknown. Preserve the existing non-name metadata collision guard.

Use the same effective observation view and alias table throughout. Preserve raw
observations, raw Bering models, edge IDs and edge preimages. Do not create peers,
proxy-to-backend paths, parents, endpoints or business labels. The visits instances
remain distinct supplied placements; SDK/runtime duplicate names do not add
replicas. Existing confirmed placement/replica overlays remain responsible for
the logical model count. The unchanged workload and independent outcome checks
will determine usefulness in the subsequent common qualification and main81.

All preparation, failed qualifications, cancelled series and early stopping stay
in the experiment cost history. Human preparation time remains unmeasured.
