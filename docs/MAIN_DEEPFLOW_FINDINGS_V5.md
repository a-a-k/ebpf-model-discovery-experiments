# Main-study DeepFlow findings

This is a partial evidence review, not the completed 81-cell conclusion. Negative
and unavailable results remain part of the study and are not reasons to rerun a
technically complete case.

## Petclinic, absent SDK, repetition 6

The [original campaign job](https://github.com/a-a-k/ebpf-model-discovery-experiments/actions/runs/41164824120/job/124430032086)
completed at source `0c98bf4520e863ab021b60d00517ee2aa49ab38e`. The
[saved-evidence reader](https://github.com/a-a-k/ebpf-model-discovery-experiments/actions/runs/41302954468)
verified the preserved inputs without replaying traffic, fitting models or
recomputing predictions. The main agent and independent skeptic reviewed its
actual facts. Both admitted this case as a valid negative result.

There were 34,800 primary observations, including 9,600 independent target
observations, with two separate guest boots. Native training and final census
both contained zero application spans. The final raw snapshots and receiver
closure were retained; internal zero kernel or exporter loss remains unproven.

Bering actually constructed four pooled models: eBPF and combined sources, each
with raw and network views. Each accepted 1,682 input shards containing 430,322
spans. A collected graph therefore existed. Its saved operation bindings could
not establish the required gateway calls to customers, visits and vets or the
corresponding uniquely reachable database requirements. The recorded reasons
were missing or ambiguous calls and unresolved required callers or channels.
These facts do not establish the underlying physical cause or universal HTTP
incompatibility.

All four operations had unavailable predictions in both views for native, eBPF,
combined AND/OR and the prespecified context baseline: 32 paired rows in total.
The 24 primary branches contained no per-operation simulation command or model;
the eight context branches reused their unavailable frozen bindings. No Sheaft
forecast was fabricated for those branches. Bering's `traces: 0` counter is not
used to infer a cause. Route-family ARI of 1.0 with `no_positive_evidence` for all
600 classified test requests does not establish useful graph discovery.

Independent target successes were 2,400/2,400 for listing owners, 2,398/2,400
for listing vets, 2,099/2,400 for creating visits and 2,100/2,400 for owner
details with visits. The declared direct-contract baseline provided predictions
for all four operations: 1, 1, 0.875 and 0.875, respectively. The same supplied
semantics and inventory remain available to the source arms. No preparation-cost
advantage is claimed; human preparation effort is unknown.

The supported interpretation is narrow: this pinned DeepFlow configuration and
repetition did not supply sufficient operation-level evidence for useful Sheaft
forecasts when native tracing was absent. The other Petclinic repetitions and
modes must still be assessed before a broader collector comparison.
