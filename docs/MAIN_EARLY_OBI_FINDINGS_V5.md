# Reviewed OBI main cases: observed limitations and conditional feasibility

These are all 26 OBI cases in the first fixed 56-packet review batch: nine
DeathStarBench, eight OTel and nine Petclinic cases. The last OBI OTel partial/8
packet is assigned to the next frozen review batch. This is not the final
81-cell comparison. All three collectors
still require the same complete matrix and original evidence checks. The original
question is whether eBPF can replace or complement missing SDK traces through
actual Bering graphs, actual Sheaft and independent application outcomes.

Root and the separate skeptic checked the source/packet identities, saved main
counts (34,800 primary attempts, 9,600 target attempts), source pins, two guests,
pre-target freezing and shared external outcomes. The qualified Actions reader
checks all available model/analysis/predicate/fault/report chains. Additional
literal review reconstructs seven DSB and six OTel models from actual observed
graphs and only the supplied metadata, verifies actual tool arguments and 100,000
trials, and binds saved reports to original worker manifests and pre-target hashes.
Neither review executes a new simulation or recomputes outcome errors.

## OTel: a supported absent-trace case and a useful combination under partial tracing

With SDK tracing absent in seeds 6/7/8, OBI supplies Bering observations supporting
browse product, add to cart and checkout. Actual Sheaft forecasts are 0.875 in
both views; observed complete-response successes are 2800/3200 for every operation
except seed 8 checkout, which has 2799/3200. Native audits retain zero SDK span
markers, exporter records and trace-file bytes during both discovery and final
validation. The absent/6 literal review verifies all three actual eBPF models and
Sheaft reports; this is conditional feasibility evidence for the original task.

In partial/7, all three original source arms have unavailable operation forecasts.
The prespecified context comparison adds 18 actual joint-model SERVER edges per
view and supports all three operations. The literal network-scope union preserves
all 203 base edges, services, endpoints and metadata, then copies exactly all 18
eligible joint edges to form 221 edges. It imports no new nodes, CLIENT guesses
or inferred physical identities. This derived union is not a Bering-emitted graph.
Its real Sheaft forecasts are 0.875 and external successes are 2800/3200 for each
operation. The extra joint Bering execution, union construction and simulation
costs remain attributed to this comparison.

This does not identify collector-caused accuracy, per-request causal truth or a
novel calculation: supplied operation contracts/placements and the strongest
equally informed direct predicate and cheap combination baselines remain explicit.
The models are conditional on nonintervened requirements staying fulfilled.
The uncontrolled PostgreSQL OOM in a different OBI/full/6 capture must not be
transferred to these absent/partial captures; see
[the separate runtime evidence](MAIN_FIXED3_AND_OTEL_RUNTIME_V5.md).

## Remaining OBI cases: Petclinic support and adverse OTel outcomes

All nine Petclinic cases support the four operations through the actual eBPF
and combined models. Partial native SDK tracing supports owners and vets but
does not support the two visit-dependent operations. Full native tracing
supports all four. Forecasts are 1 or 0.875; original external failures remain,
including owner-details successes of 2098/2400 in absent/6 against 0.875.

In OTel partial/6, the prespecified context union adds 17 observed SERVER edges
per view and forecasts 0.875. External successes are 2693/3200 for browse/cart
and 2589/3200 for checkout. Full/6 adds 16 context edges and yields 2735/3200
for browse/cart and 2653/3200 for checkout. The separately verified PostgreSQL
memory-limit OOM belongs to this full/6 capture. Full/7 also has adverse
outcomes (0.8615625–0.868125), with no established transfer of that cause;
full/8 has 0.875 for all three operations.

The remaining thirteen metadata packets were checked by both reviewers:
214 primary source/view/operation rows are available and 74 are unknown;
96 context rows are available. These are paired rows, not independent samples.
The three full OTel facts documents use an explicit facts-only 6 MiB transport
exception. The original qualified reader, scientific criteria and original
captures are unchanged.
