`a43404ec02c77e9414878632ec6248835cf7a260`: full artifact 13008608219 and
compact artifact 13007889008. Both original archive identities and ZIP hashes
were checked in Actions. No original campaign archive or raw journal was

The independent literal projection covers the complete frozen native input:
118 original direct SDK JSONL records and 1382 spans. Original and Bering-input
resource/scope/span field multisets are exactly equal, with no ambiguous span
identity. All 118 input body SHA values match the original accepted Bering
request sequence; the retained native graph has 17 services, 20 edges and
11 endpoints. Its missing checkout-to-shipping edges are not normalization,
route-alias, or dropped-ingest failures.

Both calls exist in the native source: ten checkout CLIENT spans for each of
`POST /get-quote` and `POST /ship-order`, plus ten shipping SERVER spans for
each route with the expected observed HTTP fields. Every shipping SERVER has
a parent ID absent from the same frozen native trace, while a distinct SDK
checkout CLIENT span is present. This is missing ancestry continuity within the
SDK-only input, not absence of the HTTP calls.

The follow-up at `69000a75308240fabb670dba1b73bf6c12afbf16`, run 41132172369,
read the same complete frozen eBPF prefix: 31 requests and 3932 spans. All twenty
missing native parent `(trace_id, span_id)` pairs match actual OBI checkout
CLIENT spans, ten for each route. Each match is also present in a hash-verified

`7ac011837861a1f4fbd6e795714e0e13` has shipping server parents
